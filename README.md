# Book River

## ▶️ Run Commands

### Teeno apps ek saath (root se)
```bash
cd "d:\Book River"
npm install
npm run dev
```

### Backend — port 5000
```bash
cd "d:\Book River\Backend"
npm run dev
```

### Frontend — port 5173
```bash
cd "d:\Book River\Frontend"
npm run dev
```

### Admin — port 5174
```bash
cd "d:\Book River\Admin"
npm run dev
```

| App | URL |
|---|---|
| Backend API | http://localhost:5000 |
| Frontend | http://localhost:5173 |
| Admin | http://localhost:5174 |
